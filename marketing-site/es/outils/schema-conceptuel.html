Presentación

El modelo conceptual SSP visualizado de un vistazo

Un esquema SVG interactivo estructurado en tres secciones — fuentes, vectores y receptores — alimentado directamente por los resultados de los módulos EQRS.

3 secciones estructuradas

Fuentes / medios, vectores / vías de transferencia y receptores — el marco de lectura estándar de un diagnóstico SSP.

SVG interactivo

Representación gráfica dinámica de los vínculos fuente → vector → receptor, con resalte de las vías retenidas y descartadas.

Integración con EQRS

Conexión nativa con EQRS V31.05 (vías humanas) y EQRS ECOTOX V8 (vías ecotoxicológicas: suelo → lombriz → ave, agua → pez).

Aplicación

Al servicio de la IEM y del Plan de Gestión

Interpretación del Estado de los Medios (IEM)

Visualización de las vías y receptores a investigar según la metodología ANSES IEM 2018, para justificar el alcance del estudio antes de los cálculos EQRS.

Plan de Gestión (PG)

Representación gráfica del modelo conceptual que se debe incluir en el PG según la metodología nacional SSP MEEM/MTES 2017.

Justificación científica

Argumentación de las hipótesis adoptadas (vías retenidas frente a descartadas) y validación del alcance del estudio antes de los cálculos EQRS más exigentes.

Por qué el modelo conceptual es obligatorio

En todo diagnóstico SSP profundo, el modelo conceptual no es opcional: constituye la base metodológica impuesta por el enfoque nacional de gestión de emplazamientos y suelos contaminados.

  • Condiciona la pertinencia de los cálculos: sin un vínculo fuente-vector-receptor identificado, ninguna evaluación de riesgos es admisible.
  • Estructura la IEM y el Plan de Gestión al explicitar las vías de exposición retenidas y descartadas.
  • Garantiza la trazabilidad de las hipótesis y la coherencia del conjunto del estudio.
  • Ofrece un soporte de comunicación intuitivo, comprensible para interlocutores no especialistas.

Preguntas frecuentes

Modelo conceptual y análisis de riesgos sanitarios

¿Qué es un modelo conceptual de un emplazamiento contaminado?

El modelo conceptual del emplazamiento (Conceptual Site Model) es la representación estructurada de las fuentes de contaminación, las vías de transferencia (suelo, aire, agua) y los receptores expuestos (poblaciones, ecosistemas). Constituye la base metodológica sobre la que se apoya todo análisis de riesgos sanitarios realizado en el marco de una IEM o de un Plan de Gestión.

¿Cuál es la relación entre el modelo conceptual y el análisis de riesgos sanitarios?

El análisis de riesgos sanitarios (EQRS) reconstruye la cadena fuente → vector → receptor identificada por el modelo conceptual para cuantificar la exposición de las poblaciones. Sin un modelo conceptual validado, ninguna evaluación de riesgos sanitarios es admisible según la metodología nacional de gestión de emplazamientos y suelos contaminados (MEEM/MTES 2017).

¿Es obligatorio el modelo conceptual para una IEM o un Plan de Gestión?

Sí. El modelo conceptual constituye la base metodológica impuesta por el enfoque nacional de gestión de emplazamientos y suelos contaminados para toda Interpretación del Estado de los Medios (IEM) o todo Plan de Gestión (PG).

¿Se conecta el software con las demás herramientas EQRS de GMEP?

Sí, el módulo Modelo Conceptual se conecta de forma nativa con las salidas de EQRS V9 (vías humanas) y EQRS ECOTOX (vías ecotoxicológicas), con exportación PNG/PDF para su inserción directa en los informes.
