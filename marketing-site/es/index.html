Nuestro software estrella

Motores de cálculo independientes, diseñados para las exigencias reales del terreno. Conformes a los marcos normativos franceses, EFSA 2020 y EPA. Demostraciones interactivas disponibles en el navegador, sin instalación.

Alcance geográfico de los datos utilizados

Análisis de riesgos (EQRS, ECOTOX, Johnson & Ettinger): este software se basa en valores toxicológicos y fisicoquímicos de referencia reconocidos internacionalmente (US EPA, ANSES, EFSA, INERIS, ECHA). Puede utilizarse en estudios realizados en cualquier país.

Hidrogeología (Abatimiento de nivel freático, Transferencia Suelo → Acuífero → Captación, Modelización GEP/DLE, Dimensionamiento ANC): este software recupera automáticamente los datos geológicos y piezométricos de las bases de datos nacionales francesas (BRGM, Hub'Eau). Esta automatización está actualmente operativa para Francia. Para un estudio realizado en otro país, los parámetros hidrogeológicos necesarios deben introducirse manualmente por el usuario, a la espera de la automatización progresiva de las bases de datos por país.
